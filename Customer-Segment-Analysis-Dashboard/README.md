# Customer Segment Analysis Dashboard

## Overview

This project analyzes customer purchasing behavior using Python, SQL, SQLite, Excel, and Power BI. It demonstrates the complete analytics workflow from data preprocessing to dashboard development.

## Tech Stack

- Python
- SQL
- SQLite
- Power BI
- Microsoft Excel

## Key Features

- Data Cleaning
- Exploratory Data Analysis
- Customer Segmentation
- Revenue Analysis
- KPI Dashboard
- Interactive Filters

## Skills Demonstrated

- Data Analysis
- Dashboard Design
- SQL Querying
- Business Intelligence
