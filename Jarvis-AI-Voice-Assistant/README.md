# 🤖 JARVIS – AI Voice Assistant

## 📌 Overview

JARVIS is a Python-based desktop voice assistant that performs everyday tasks through voice commands. It combines speech recognition, text-to-speech, web search, and a graphical interface to provide an interactive user experience.

---

## 🎯 Objective

Develop a voice-controlled desktop assistant capable of recognizing commands, retrieving information, and automating common tasks.

---

## 🛠️ Technologies Used

- Python
- Tkinter
- SpeechRecognition
- pyttsx3
- Requests
- BeautifulSoup
- Wikipedia API
- NLTK
- Pillow
- yt-dlp

---

## ✨ Features

- 🎤 Voice Recognition
- 🔊 Text-to-Speech
- 🌐 Google Search
- 📖 Wikipedia Summary
- 🎵 Play Songs on YouTube
- ⏰ Date & Time
- 😂 Joke Generator
- 🖥️ Interactive GUI with Animations
