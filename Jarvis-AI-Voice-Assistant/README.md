# JARVIS – AI Voice Assistant

## 📌 Overview

JARVIS is a Python-based voice assistant developed to automate everyday tasks using voice commands. The assistant can recognize speech, respond with synthesized voice, perform web searches, open applications, and execute various system operations.

---

## 🎯 Objective

To build a voice-controlled desktop assistant that enhances productivity through speech recognition and task automation.

---

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- Tkinter / CustomTkinter
- Webbrowser
- Requests
- BeautifulSoup
- NLTK

---

## ✨ Features

- 🎤 Voice Command Recognition
- 🔊 Text-to-Speech Responses
- 🌐 Web Search
- 📂 Open Applications & Websites
- 🤖 Conversational Interaction
- ⚡ Task Automation
