# Sales & Profit Analysis Dashboard

## 📌 Overview

This project presents an interactive Microsoft Excel dashboard designed to analyze sales and profit performance across different products, categories, and regions. The dashboard provides valuable business insights using Pivot Tables, Pivot Charts, Slicers, and advanced Excel features.

---

## 🎯 Objective

To monitor sales performance, identify profit trends, and support business decisions through interactive reporting.

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Functions

---

## 📊 Dashboard Features

- Sales Overview
- Profit Analysis
- Regional Performance
- Category-wise Sales
- Interactive Filters
- KPI Summary

---

## 💡 Key Insights

- Identified top-performing product categories.
- Compared sales and profit across different regions.
- Analyzed overall business performance using interactive dashboards.
- Enabled dynamic filtering for detailed analysis.
